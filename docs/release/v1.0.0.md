### Findings fixed in this release

| Finding                                                                                                                                      | Severity               | Fix                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------ |
| Presence ("online") and typing used **public** Realtime channels named after the workspace id; anyone signed in who knew the id could listen | Medium                 | Private channels with Realtime Authorization policies (migration 0025)         |
| Vault PDF previews were blocked by the CSP (no `frame-src` for Storage)                                                                      | Low (broken feature)   | `frame-src` allows the project's Storage origin                                |
| Initial JavaScript was ~350 kB gzipped, over the 300 kB budget; route splitting had no effect                                                | Medium (performance)   | Pages lazy-load from their own modules; `check:bundle-size` in CI (now 249 kB) |
| Four controls had accessible names that did not contain their visible text                                                                   | Medium (accessibility) | Names fixed; axe audit on 18 pages in dark and light themes in CI              |

**Open high or critical issues: none.**
